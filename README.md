# n-Beta · NBA Probability Lab

**用概率理解 NBA 球队实力、单场对阵和赛季走向。**

n-Beta 是一个 NBA 预测与可视化项目。它根据比赛结果更新球队评级，估计单场胜率与预期分差，再通过蒙特卡洛模拟，把剩余赛程转化为球队胜场分布、季后赛晋级概率和夺冠概率。

项目关注的不只是“谁排第一”，还包括预测有多大不确定性、哪些因素影响结果，以及模型的判断是否与实际表现相符。你可以从联盟排名进入一支球队，查看它的实力变化、剩余赛程和赛季前景，也可以在单场沙盒里调整主场与伤病条件，观察胜率变化。

## 可以用它做什么

| 视图 | 可以了解的问题 |
| --- | --- |
| **联盟排名** | 哪些球队更强？当前战绩与模型实力评价是否一致？ |
| **胜场分布** | 球队预计赢多少场？结果可能落在哪个范围？ |
| **实力走势** | 球队评级如何随比赛变化？先验与伤病折损分别贡献了多少？ |
| **单场比赛** | 对阵双方的胜率和预期分差是多少？情境调整会怎样改变预测？ |
| **球队详情** | 一支球队的阵容、比赛结果、剩余赛程和晋级前景如何？ |
| **模型与审计** | 模型使用哪些参数？概率预测的损失、校准与数据覆盖情况怎样？ |

看板支持球队搜索、联盟/分区筛选、深浅主题、移动端浏览，以及 PNG 分享卡和 CSV 数据导出。

## 预测如何产生

整个流程分为三个部分：

1. **更新球队实力**：从球队先验出发，根据每场比赛的比分差更新评级及其不确定性，使用启发式修正降低极端分差的影响。
2. **计算单场概率**：结合双方评级、主场、休息与赛程密度等因素估计净胜分，使用 Student-t 分布计算主队获胜概率，并加入当前伤病折损。
3. **模拟赛季路径**：默认运行 100,000 次模拟，汇总剩余比赛、附加赛和季后赛的结果，生成胜场分布、种子排名及各轮晋级概率。

当前公开版本采用带启发式修正的近似状态更新模型。模型公式、参数含义和近似条件见 [模型说明](docs/MODEL.md)。

## 项目结构

Python 离线管道负责计算并导出 JSON/CSV；HTML、CSS 和 D3 构成六视图看板。前端无需 Node 构建或后端服务，可以直接读取仓库附带的数据快照。

```text
nBeta/
├── index.html          # 看板入口
├── assets/             # 页面交互、样式与本地 D3
├── pipeline/           # 数据加载、评级、模拟与校验
├── data/
│   ├── seed/           # 输入快照
│   └── *.json, *.csv   # 看板数据与导出文件
├── tests/              # 生产回归与浏览器验收
└── docs/               # 模型公式、数据来源与验收记录
```

## 快速体验

仓库附带可直接浏览的数据，无需先运行模型：

```sh
git clone https://github.com/leoq77777/nBeta.git
cd nBeta
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。通过本地 HTTP 服务访问，避免直接打开 HTML 时浏览器限制数据加载。

如需重新计算，使用 Python 3.12+ 创建环境并运行管道：

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pipeline.build_daily --sims 100000
```

开发时可将模拟次数改为 `1000`。随机种子与模型参数位于 `pipeline/config.py`。

## 当前数据与限制

当前版本基于固定数据快照。重建会重新计算预测，不会自动获取最新赛果；`data_through` 表示比赛数据截至日期，`as_of` 表示构建时间。

- **赛程覆盖**：快照包含 1,200 场赛程和 107 场已完赛比分，已与 ESPN 核对。每队目前有 80 场已知赛程；NBA Cup 决定的另外两场尚未纳入模拟，胜场和晋级预测因此不覆盖完整 82 场赛季。
- **模型输入**：先验评级、球员价值及历史伤病的生成方法或逐时点可用性仍未验证，部分球员统计与球队赛果的截止时间不同。
- **评估范围**：界面评分来自当前快照上的逐场回放，不能视为经过确认的独立样本外表现，也不能据此声明市场优势。
- **近似假设**：比分清洗、球员攻防拆分和伤病恢复使用代理或启发式假设；同战绩排序尚未实现官方完整决胜规则。

详细核验见 [数据来源与核验](docs/SEED_VERIFICATION.md)，第三方文件说明见 [来源声明](THIRD_PARTY_NOTICES.md)。
