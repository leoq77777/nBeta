# n-Beta · NBA Probability Lab

n-Beta 是一个观察 NBA 球队战绩走向的统计建模项目。它结合球队历史、近期比赛、球员 Box Score 与赛程信息，展示单场胜率和预期比分，以及球队评级、赛季胜场分布和季后赛概率。后续研究方向是更可靠的球员能力与阵容影响估计。

**[在线查看](https://leoq77777.github.io/nBeta/)** · 支持 CN / EN 切换和明暗主题。

## 当前功能

- **球队排名与评级**：战绩、球队评级及不确定性区间、近期走势和赛季预测。
- **单场比赛**：未来对阵的主队胜率、预期分差、总分及双方预期得分；查看完赛结果。
- **赛季分布**：模拟胜场分布、排名与季后赛概率。
- **球队与球员**：球队详情、本赛季球员表现榜、前20名球员资料和投篮分布。球员榜使用 Game Score 等 Box Score 产出指标，不能等同于控制队友、对手后的真实影响力或因果贡献。
- **模型审计与误差追溯**：模型版本、数据时间、预测阶段贡献、样本覆盖及已结算赛前预测的误差诊断。

## 当前模型与验证状态

**线上单场预测使用冻结的 Additive v1。** 它把动态球队基线与赛程、球队过程特征、球员历史统计及近期阵容代理结合，通过分差与总分模型产生胜率和双方预期比分。模型使用66个分差特征、74个总分特征，历史训练数据覆盖2015–16至2025–26常规赛。每日数据更新改变输入和动态状态，**不会自动重训回归权重**。

球队评级、赛季胜场与季后赛模拟仍使用旧版评级／模拟引擎。单场模型通过历史开发验收，不代表赛季模拟也完成了相同验收。页面中的 Legacy 描述与历史成绩应按各自模型版本解读。

最新开发实验尝试了多赛季球员基础、球员内固定效应、分差／总分窗口解耦及进攻／防守篮板拆分。在7个赛季、8,289场前滚测试中，固定效应历史在线版的胜率 Log Loss 为0.617945，原 Additive 为0.619140；比分 RMSE 分别为11.6843和11.6888。**相对线上基准的优势未通过本轮多重比较校正，因此未替换线上模型。** 这些历史年份已被多轮研究使用，结果属于开发证据；实际赛前预测另以不可回填的前向记录持续评估。

## 数据与每日更新

前端由 GitHub Pages 托管，读取后端发布的版本化 HTTPS 数据快照。后端采集 ESPN 比赛结果及球员统计，完成校验后发布；构建失败时保留上一份快照。页面分别展示构建时间、比赛数据截止时间和源数据检查时间。

每日更新安排在 **America/Los_Angeles 23:00**，并在23:30和次日00:00补查，随夏令时变化。它是定时快照，不是逐回合直播。名单、伤停与未来赛程的可用性仍有限，不应根据刷新时间假定所有字段都已同步。

## 本地运行

需要 Python 3.10+。使用仓库附带快照预览页面：

```sh
python3 -m http.server 8080
```

打开 <http://localhost:8080>。前端默认优先读取已配置的线上快照；本地附带数据用于回退。

安装依赖、检查生产代码并重建附带种子快照：

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m pipeline.build_daily --sims 100000
```

本地种子构建会更新 `data/` 中的导出，默认运行旧版引擎。复现线上 Additive 推理还需要经过散列校验的历史输入及已配置的模型包；公开仓库中的冻结系数文件本身不足以完成这一步。详见 [部署说明](deploy/README.md)。

## 解释边界

- 评级和球员能力都是给定数据与假设下的估计，不是可直接测量的真实实力。
- 当前阵容输入是历史出场构造的代理，尚未完整覆盖赛前伤停、真实轮换、五人组合化学反应和具体球员对位。
- 单场比分使用总分／分差联合正态近似，未显式模拟加时；历史统计可用时间仍包含协议假设。
- 市场数据缺失时保持缺失，不据此生成已验证的市场优势结论。

公开仓库包含已采用的应用、部署代码、冻结生产模型和运行所需的公开快照；未采用的研究实现、原始历史缓存、实验权重及服务器配置保留在本地。第三方素材及依赖说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
