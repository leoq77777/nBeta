# 公开实现范围

采用 Python 离线管道与 HTML/CSS/D3 六视图静态看板，当前实现公式见 `MODEL.md`。

1. 数据正确性：统一别名、按实际赛程计算胜负与分布，验证输入和导出不变量。
2. 审计：按当前快照已完赛比赛计算逐场赛前预测评分；无已验证先验发布时间，不声明独立样本外成绩；不将模型让分当作市场数据。
3. 前端：排名、胜场分布、评级历史、比赛、球队和模型审计；支持主题、筛选、沙盒、PNG/CSV 导出及窄屏显示。
4. 运行：依赖清单、离线构建、生产回归测试和 CI。
5. 验收：已有 100,000 次完整模拟、数学不变量及桌面/移动浏览器检查，历史证据见 `ACCEPTANCE.md`。

赛程、比分与球员身份的核验见 `SEED_VERIFICATION.md`；先验与球员价值仍未验证。当前模拟按已知每队 80 场赛程运行，NBA Cup 尚未确定的两场没有补造。

本次只公开仓库，未配置线上站点部署。发布文件清单与排除范围见 `RELEASE_SCOPE.md`。
