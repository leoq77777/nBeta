# 种子数据核验

本轮不改写 `data/seed/`，不重新拟合模型。核验依据是外部原始记录和文件哈希，而非只检查输出能否运行。

## 来源定位

六份 CSV（teams、schedule、players、run、history、win_dist）与公开仓库以下固定提交逐字节一致：

https://github.com/chronicaria/chronicaria.github.io/tree/dc200d996eb9f7daa7790bad91c088d50821b65b/data

提交时间 2026-11-03 05:58:59 UTC；种子 run.as_of 为 2026-11-03 05:58:45 UTC。该仓库 README 说明文件均由另一个 source kit 的夜间任务生成，仓库本身未公开计算源 kit。

`logos.json` 与固定提交的 blob 不同（与探测时分支目录的 blob 一致）。它是展示资产，不用于预测。完整 git blob SHA 和每份本地文件 SHA-256 均保存在机器报告中。

**确认上游导出来源，不等于确认上游模型正确，也不等于确认历史时点可用性。** 当前 API 可见最早 teams.csv 提交是 2026-10-26 18:44:57 UTC，晚于 10 月 20 日开赛。没有证据证明当前 rating_prior 和市场总胜场在回放第一场比赛前已可获得；这属于缺乏证据，不能据此断言泄漏一定发生。

## 外部字段核对

读取 ESPN 30 队的 2027 season / regular-season schedule、30 队 roster 和原快照 107 场 final 比赛 summary，共 167 份 ESPN 记录；另存两份 GitHub 来源记录。每份记录包含 URL、抓取时间与压缩原始响应。

| 字段 | 检查结果 | 范围与限制 |
| --- | --- | --- |
| 比赛 ID、ET 日期、主客球队 | 1,200 / 1,200 一致 | 两队别名统一后比对 |
| 开赛时间 | 1,200 / 1,200 一致 | 按实际时间而非字符串格式比对 |
| 已完赛状态与比分 | 107 / 107 一致 | 不使用快照未完赛比赛来“修正”历史 |
| 球队战绩 | 30 / 30 与种子已完赛记录一致 | 内部核对，与已验证比分交叉支持 |
| 球员 ID 与姓名 | 484 / 484 一致 | Unicode、标点归一化 |
| 球员所属球队 | 484 / 484 与抓取时阵容一致 | 当前 roster 不等于历史每一天 roster |
| 球员 GP | 154 / 484 与截至 11 月 2 日同队 box score 聚合一致 | 330 人不一致，325 人少 1 场、5 人少 2 场 |
| 球员 MPG | 442 个非空值中 258 个在 ±0.55 分钟内一致 | 原始 box score 常是整数分钟，仅判兼容性；42 人未提供 MPG |

使用截至 11 月 1 日的 box score 按球员 ID 聚合 GP 时，476 / 484 与 seed GP 一致。这是球员统计大部分滞后于截至 11 月 2 日球队赛果的证据，并不意味着其余 8 人的差异原因已解释。

示例：Nickeil Alexander-Walker 的 seed GP=7，而已验证的 107 场比赛中有 8 次出场；seed MPG=30.0，整数分钟聚合约 30.125。GP 截止时间不同，即使 MPG 相近也不属于同一快照。

## 80 场赛程的性质

NBA 官方 2026–27 赛程公告说明：初始明确日期和对手的是每队 80 场，另外两场依据 NBA Cup Group Play 结果安排。

https://pr.nba.com/2026-27-nba-regular-season-schedule

因此，1,200 场不是已证实的采集漏项。之前把它直接称为“缺失 30 场”不够准确，应称为尚未确定的 30 场。当前模型依然只模拟这 80 场，**没有将未确定的两场加入赛季模拟**，所以预测不是完整 82 场赛季预测，且种子/晋级概率也受这一缺口影响。

run.csv 中 games_left=1123，而实际列表未赛=1093：前者相当于 1230−107，后者是1200−107。二者口径不同；不能直接认定某个数字凭空捏造。

## 尚不能验证的模型输入

- rating_prior 的原始计算方法、训练样本、每次预测前的可用时间；历史表上标注的日期不足以证明发布时间。
- vegas_total 的完整 bookmaker、抓取时间、盘口版本和去水/共识口径。公开报价相近不能替代同一时点同一来源验证。
- 球员 value 的构造公式、单位和训练数据；球员身份真实不意味着 impact value 经验证。
- 历史伤病 status、p_out、return_date 的逐时点快照及其概率校准。
- 上游历史评级、胜场 PMF 和季后赛概率的生成过程；它们本身是另一套预测模型的导出，不是可直接充当真实标签的观测数据。

结论：可确认赛程与比分字段，以及球员身份/当前所属队；球员统计存在快照滞后；先验、价值及历史伤病还不能作为已验证的回测输入。当前 107 场评分仍不能升级为无泄漏样本外成绩。

## 重现与证据

```sh
source .venv/bin/activate
python -m pipeline.verify_seed
# 重新获取最新外部证据：
python -m pipeline.verify_seed --refresh
```

默认使用 `data/verification/*.json.gz` 缓存；`--refresh` 会覆盖该目录的外部证据缓存，不改动 seed。机器报告为 `data/verification/seed_audit.json`，包含全部差异、URL、时间和哈希。该目录不参与当前 Pages 部署。

该工具是诊断报告，不以进程退出码表示种子全部通过。球员 MPG 容差只处理整数分钟误差，不解释来源统计截止时间差异。
